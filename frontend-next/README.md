# frontend-next 静态原型说明

## 定位

`frontend-next/` 不是正式前端实现，只是一个 **高保真静态原型**。

它的作用是：

- 提前看到毕业设计最终成品大概长什么样
- 帮助确认页面结构、图表展示和业务流程
- 作为后续 Vue 3 正式实现的视觉与信息架构参考

正式路线仍然以 `zzz-docs/开发指导版PRD-粮仓环境数据预测管理平台.md` 为准：

- 正式前端：`Vue 3 + Vite + Vue Router + Pinia + Element Plus + ECharts + Axios`
- 正式后端：`Spring Boot + MyBatis + MySQL`

## 当前原型覆盖页面

当前静态原型已经覆盖以下页面：

1. 登录页
2. 仪表盘
3. 用户管理
4. 仓库管理
5. 环境数据页
6. 温度预测页
7. 展示大屏

## 每个页面表达什么

### 1. 登录页

用于表达最终系统的入口状态：

- 用户名密码登录
- 角色识别
- 进入后台或直接查看展示大屏

### 2. 仪表盘

用于表达系统首页应展示的核心内容：

- 粮仓数量
- 今日采样量
- 待处理预警
- 已归档预测
- 今日采样趋势
- 仓库健康度
- 近期预警
- 最近采样记录
- 系统主流程

### 3. 用户管理

用于表达毕业设计里的角色与权限能力：

- 用户列表
- 角色说明
- 页面级权限矩阵

### 4. 仓库管理

用于表达粮仓基础档案维护能力：

- 仓库列表
- 负责人、容量、装载率
- 当前状态
- 当前选中仓库详情
- 运维待办

### 5. 环境数据页

用于表达数据管理主链路：

- 按仓库、指标、时间筛选
- 手工录入 / 导入入口
- 温湿度趋势图
- 重点指标对比
- 环境数据表格
- 导入与预处理说明

### 6. 温度预测页

用于表达预测模块的完整闭环：

- 选择仓库、指标、预测步数
- 触发预测任务
- 查看历史温度和未来预测曲线
- 查看风险提示
- 查看预测结果列表
- 查看预测归档记录

### 7. 展示大屏

用于答辩或展示时的一屏概览：

- 关键指标
- 仓库运行态势
- 环境趋势与预测走势
- 重点预警
- 重点仓库卡片
- 预测调度看板
- 系统主流程

## 这个原型和正式系统的关系

这套原型解决的是“最终成品看起来像什么”的问题，不解决真实业务联调。

正式版落地时会做这些替换：

- 把当前本地 mock 数据替换为后端 API
- 把 Next + Ant Design 页面改为 Vue 3 + Element Plus 实现
- 把静态图形替换为正式 ECharts 图表
- 把静态预测结果替换为真实预测接口返回

## 你现在可以怎么用它

如果你现在想看成品预期，这个目录已经可以帮助你确认三件事：

1. 最终系统的页面范围
2. 每个页面会承载什么信息
3. 答辩时可以怎么演示“登录 -> 数据 -> 图表 -> 预测 -> 归档”

## 启动

```powershell
cd frontend-next
npm run dev
```

或构建验证：

```powershell
cd frontend-next
npm run build
```
