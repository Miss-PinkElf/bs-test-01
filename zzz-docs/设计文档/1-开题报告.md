## 一、选题背景与研究意义

### 1.1 选题背景

#### 1.1.1 行业背景

粮食安全是国家战略安全的核心组成部分，粮仓作为粮食储备的重要载体，其安全管理水平直接关系到国家粮食战略储备的质量与稳定性。当前，我国粮食年产量持续保持在较高水平，粮食储备规模不断扩大，仓储点数量众多、分布广泛，传统依赖人工巡检与经验判断的管理模式已难以适应现代粮仓管理的精细化需求。粮仓内部温湿度变化、局部发热、害虫侵扰等问题若不能及时发现与处置，将对储粮安全造成严重威胁。与此同时，决策科学化的需求也在推动粮食储存管理方式从传统经验模式向现代数据驱动模式加速转型。[1]

#### 1.1.2 技术发展趋势

近年来，物联网、无线通信、人工智能及机器人技术的迅猛发展，为粮仓智能化管理提供了坚实的技术基础。在无线通信领域，LoRa、5G、GSM 等多种传输技术已被广泛应用于粮仓环境数据的远程采集与传输，实现了大范围、低功耗的实时监测。在系统架构层面，数字孪生与区块链技术的引入，为构建粮仓全生命周期监测体系提供了新的技术路径。在智能装备层面，粮仓巡检机器人技术的兴起，正推动粮仓管理从“有人值守”向“无人自主巡检”转变。云计算与边缘计算的协同应用，则进一步增强了粮仓监测系统的数据处理能力与响应实时性。[2]

### 1.2 研究意义

#### 1.2.1 理论意义

本研究在算法层面，针对粮仓巡检机器人路径规划问题，对蚁群算法进行改进与优化，有助于拓展智能优化算法在受限空间环境下的理论应用边界，为相关算法研究提供新的实验场景与验证依据。在系统建模层面，引入数字孪生技术构建粮仓虚拟映射模型，有助于推动物理系统与数字模型融合理论在农业仓储领域的深化应用。在感知理论层面，多传感器融合与异常识别方法的研究，对传感器网络理论及多源数据协同处理机制的完善具有一定参考价值。

#### 1.2.2 应用价值

在实践层面，本研究成果的推广应用有望显著降低粮仓人工管理成本，提升仓储安全事件的早期预警与快速响应能力，从而减少粮食损耗，保障国家粮食储备安全。智能监测系统的部署，能够实现仓储环境的全天候、多维度、精细化管控，有效弥补传统人工巡检在覆盖范围与响应时效上的不足。此外，系统所积累的海量运行数据，亦可为粮仓管理决策的科学化与精准化提供持续的数据支撑，具有显著的经济效益与社会价值。

## 二、国内外研究现状

### 2.1 国内研究现状

#### 2.1.1 无线通信与环境监测系统研究

国内学者在粮仓环境监测领域开展了大量工程化研究，形成了以多种无线通信技术为核心的系统化解决方案。在 LoRa 技术应用方面，张世昂等设计并实现了基于 LoRa 的粮仓温湿度采集系统，验证了 LoRa 在粮仓复杂环境下的传输可靠性 [3]；闫坤程等进一步将 LoRa 技术与粮仓环境监控系统深度集成，形成了较为完整的技术方案 [4]。甄彤等则将 LoRa 通信与传感技术结合，构建了面向储粮温度的变频通风测控系统，在通风调控智能化方面取得了实质性进展 [5]。在 5G 与其他通信技术应用方面，丁华峰等基于 5G 无线通信技术实现了无人值守粮仓的多点温度远程监测，显著提升了系统的实时性与覆盖能力 [6]；李怀亮等则探索了基于 GSM 网络的粮仓自动控制系统，拓展了粮仓远程监控的技术路线 [7]。此外，戴永彬提出了基于多传输模式的小型粮仓环境监控系统，通过多模式传输机制提升了系统的灵活性与适应性 [8]。

#### 2.1.2 云平台与智能系统集成研究

随着云计算技术的普及，国内研究逐步向系统集成与平台化方向延伸。纪帆等依托华为云平台构建了粮仓环境监测系统，实现了数据的云端汇聚与远程管理 [9]。马爱霞从系统架构层面提出了基于数字孪生技术与区块链的智能粮仓监测系统设计方案，为粮仓数字化管理提供了兼顾数据可信与状态映射的新型架构思路 [10]；在害虫智慧化检测方面，马爱霞还对相关研究进展进行了系统综述，指出视觉识别与人工智能技术的融合是提升害虫检测精度的重要方向 [11]。邢硕等则面向黑龙江大豆粮仓场景，设计了基于单片机的多参数智能监控系统，在区域专项应用层面体现了良好的工程实践价值 [12]。

#### 2.1.3 传感器网络与异常识别研究

在感知层技术与异常事件识别方面，李彬彬等基于传感器网络开展了智能粮仓局部发热识别与响应机制研究，提出了针对粮食储存中发热异常的检测与处置方法，对提升仓储安全预警能力具有重要的参考意义 [13]。朱斌彬基于 Proteus 仿真平台对粮仓温湿度监测控制系统进行了系统仿真验证，为硬件系统设计提供了低成本的前期验证手段 [14]。

#### 2.1.4 巡检机器人与路径规划研究

在粮仓机器人技术领域，国内研究正处于快速发展阶段。张硕针对粮仓巡检机器人的路径规划问题，提出了基于改进蚁群算法的解决方案，在提升路径规划效率方面取得了一定进展 [15]。宋鸿杰等专注于巡检机器人的地图构建方法研究，为机器人在粮仓环境中实现自主导航奠定了感知基础 [16]。梁卫强等则基于 EDEM-ADAMS 联合仿真方法，开展了粮仓机器人参数优化与试验研究，从机械结构与运动性能优化角度为巡检机器人的工程化设计提供了重要支撑 [17]。

#### 2.1.5 粮仓被动式调控研究

在粮仓环境调控领域，刘佳怡等以丰图义仓为典型案例，系统解析了粮仓被动式环境调控技术的设计原理与实现路径，为传统建筑智慧与现代仓储管理的有机融合提供了有价值的借鉴 [18]。

### 2.2 国外研究现状

#### 2.2.1 粮食储存决策与管理方法研究

在粮食储存管理的决策方法层面，国外学者已围绕储粮策略的系统化分析开展了较为深入的研究。Chen 系统梳理了粮食储存管理中从传统经验方法到现代分析技术的演进路径，重点探讨了干燥技术在粮食储存决策中的核心作用，揭示了现代分析方法对于提升储粮科学管理水平的重要意义。该研究表明，粮食储存管理的现代化转型不仅依赖于监测手段的技术升级，更有赖于科学决策框架的系统性建立 [19]。

#### 2.2.2 粮食生产与储存的可持续性研究

在粮食生产与储存的可持续发展方向上，Bakar 等针对马来西亚主要粮食产区，评估了替代湿润与干燥水稻种植技术在全生命周期内温室气体减排方面的潜力，为粮食生产端与储存端的绿色化管理提供了重要参考 [20]。Telles 等则在巴西南部开展了多元作物轮作对产量稳定性影响的研究，指出多元化种植模式虽能提升产量稳定性，但需配套科学的粮食储存策略方能实现综合经济效益的最大化，从而将粮食储存管理的战略地位提升至农业生产全链条的重要环节 [21]。

### 2.3 现有研究的不足

#### 2.3.1 技术层面和应用推广层面

在技术层面，尽管国内外在粮仓智能监测与管理领域取得了较为丰富的研究成果，但现有研究在技术层面仍存在若干值得关注的不足。第一，单一参数监测主导，多维感知融合不足。现有大多数系统以温湿度监测为核心，对局部发热、有害生物、气体浓度等多参数协同感知的研究尚不充分，难以实现对粮仓环境异常状态的全面、立体感知。第二，巡检机器人路径规划算法的环境适应性有待增强。现有改进算法在标准场景下表现良好，但面对粮仓内货架密集、障碍物动态变化等复杂工况时，算法的鲁棒性与全局最优收敛能力仍有较大提升空间。第三，系统实时性与响应能力存在瓶颈。部分研究受限于通信传输时延与边缘计算资源不足，在异常事件快速响应方面表现欠佳，尚未实现真正意义上的实时闭环管控。

在应用推广层面，现有研究同样面临若干制约。一方面，系统的场景适应性不足，多数研究成果针对特定仓储规模或特定粮食品种设计，跨场景、跨品种的泛化应用能力较弱。另一方面，系统部署成本偏高，尤其是涉及机器人装备、云平台接入及数字孪生建模的综合方案，在基层粮仓的大规模推广中面临较高的经济门槛。此外，现有研究中感知层数据采集与决策层智能分析之间的深度融合仍显不足，数据价值挖掘深度有限，距离真正实现“数据驱动、智能决策”的管理目标仍存在一定差距。

#### 2.3.2 研究思路

综合以上分析，当前粮仓智能管理领域在多参数融合感知、巡检机器人自主路径规划、系统轻量化部署以及感知-决策一体化架构设计等方面存在明显研究缺口。本研究拟以此为切入点，聚焦粮仓智能监测系统的关键技术问题，重点围绕以下几个方向展开研究：其一，构建面向粮仓复杂环境的多参数融合感知体系，通过集成温湿度、气体浓度、图像识别等多类型传感器，实现对仓储环境异常状态的全维度、高精度感知；其二，针对粮仓巡检机器人的自主导航需求，研究适应粮仓复杂工况的路径规划算法改进方法，提升机器人在密集障碍、动态环境下的路径优化效率与鲁棒性；其三，探索轻量化系统部署方案，在保障功能完整性的前提下降低系统硬件与运维成本，增强方案在基层粮仓中的工程可行性；其四，设计感知层与决策层深度协同的系统架构，充分挖掘多源监测数据的潜在价值，推动粮仓管理向“感知-分析-决策”一体化的智能管控模式演进。本研究的开展，旨在弥补现有研究的技术短板，为我国粮仓智能化管理体系的建设提供理论支撑与实践参考。

## 三、本课题要研究或解决的问题和拟采用的研究手段（途径）

### 3.1 本课题要研究或解决的问题

本课题的核心目标是设计并实现一个基于 Spring Boot 框架的粮仓环境数据预测管理平台，主要解决以下几个具体问题。

1. 粮仓环境数据的统一接入与规范化存储问题。当前粮仓监测系统普遍存在数据格式不统一、历史数据难以追溯的问题。本平台需要设计合理的数据库表结构，支持温度、湿度等多类环境指标的分类存储，并提供基于时间范围的高效查询接口，为后续分析与预测提供数据基础。
2. 粮仓环境数据的趋势预测问题。仅靠实时监测数据难以提前发现潜在的粮情风险。本平台拟针对温度这一最关键的粮仓指标，结合历史时序数据，在后端集成轻量级预测模型，如基于滑动平均或简单回归的方法，对未来短期内的温度走势进行预估，并将预测结果以图表形式反馈给管理人员，辅助其作出储粮管理决策。
3. 平台功能模块的完整性与可用性问题。平台需要具备用户管理、仓库信息管理、环境数据录入与查询、数据可视化展示、预测结果展示等基础功能模块，各模块之间逻辑清晰，接口规范，确保系统在功能上满足粮仓日常管理需求。

### 3.2 拟采用的研究手段（途径）

#### （一）文献分析

在需求分析与技术选型阶段，系统梳理国内外关于粮仓环境监测、数据预测、物联网平台架构等方面的学术文献，重点参考近年来的研究成果，明确本平台在数据预测与可视化方面的功能定位。同时，通过文献调研厘清 Spring Boot 框架的典型应用模式、MySQL 关系型数据库的设计规范，以及 ECharts 等前端可视化组件的集成方式，为系统详细设计提供理论依据。

#### （二）案例分析

在系统设计阶段，对现有粮仓管理系统的典型案例进行功能分析与对比。分析其功能模块划分方式、前后端交互逻辑及数据展示方案，归纳已有系统的优缺点，针对性地优化本平台的功能结构。在预测模块设计上，结合本平台实际数据规模选取计算复杂度适中的预测算法，避免过度依赖训练数据的复杂深度学习模型。

#### （三）系统设计与实现路线

在技术实现层面，本平台采用前后端分离的架构模式。后端基于 Spring Boot 框架，提供 RESTful 风格的数据接口，使用 MyBatis 完成数据持久化操作，数据库选用 MySQL；前端采用 Vue.js 结合 ECharts 实现数据的动态可视化展示，包括折线图、柱状图等常用图表形式。系统的核心开发流程为：需求分析 -> 数据库设计 -> 后端接口开发 -> 前端页面开发 -> 功能联调与测试。

预测功能的实现思路为：将历史温度数据按时间序列从数据库中提取，在后端通过 Java 实现简单的线性回归或加权移动平均算法，输出未来若干时间步的温度预测值，并通过接口返回前端进行图表渲染。此方案无需依赖外部机器学习框架，实现成本低，结果可解释性强，适合本课题的技术条件与研究范围。

整体而言，本课题的研究工作立足于现有文献与案例的充分调研，以功能完整、逻辑清晰的平台实现为最终目标，重点在于系统的架构设计合理性与数据预测功能的有效集成，不追求预测算法的最优性能，而着重于平台整体的可用性与工程完整性。

## 四、指导教师意见

### 4.1 对文献综述的评语

该生文献综述结构清晰，涵盖了从 ZigBee 到 NB-IoT、从单点到多传感器融合、从数据展示到趋势预测的技术演进路径，显示出较好的文献调研能力。文献数量充足，类型涵盖期刊、学位论文，基本满足开题要求。建议在后续研究中进一步加强对近几年 Spring Boot 相关平台设计文献的引用，并在综述中增强对不同技术路径的对比分析，提升综述的批判性与针对性。

### 4.2 对本课题的深度、广度及工作量的意见和对设计（论文）结果的预测

本课题围绕“粮仓环境数据预测管理平台”展开，涵盖数据采集接入、时序预测、可视化展示等核心功能，选题具有明确的应用背景和工程实践价值。研究目标清晰，拟解决的问题聚焦于“数据存储规范、趋势预测、平台功能完整”，符合本科毕业设计的深度要求。技术路线采用 Spring Boot + Vue + ECharts + MySQL，架构合理，预测模块选用轻量级回归算法，兼顾可行性与创新性。整体工作量适中，功能模块完整，具备良好的工程实现基础。预期可实现一个功能完备、界面友好、具备基本预测能力的数据管理平台。建议在后续开发中注重数据模拟与接口联调，确保系统可演示、可运行。
