# 2026-04-12 Phase 12 图表时间范围与长 x 轴收口归档

## 范围

本次归档收口 Phase 12，目标是解决正式前端里目标图表“时间轴过长、展示不全”的问题，并保持原有业务语义不被污染。覆盖范围：

- `frontend/src/views/DataView.vue` 的粮温汇总趋势图
- `frontend/src/views/PredictionView.vue` 的实际值 / 预测值双线图
- `frontend/src/views/BigScreenView.vue` 的粮温趋势主图

## 交付结果

### DataView

- 粮温汇总趋势图首次进入粮温主线时默认落在最近 30 天。
- 继续沿用原有 `grainSummaryRange` 共享查询口径，不新增第二套图表查询状态。
- 图表补齐 `axisLabel` 压缩、密集时旋转、`dataZoom` 和更大的 `grid.bottom`，保留“当前目标主线 + 最高温参考线”语义。

### PredictionView

- 实际值 / 预测值双线图新增图表级时间范围控件。
- 默认展示最近 7 天窗口；当任务时间跨度不足 7 天时退化为展示完整时间线。
- 图表时间范围只影响双线图显示，不回写任务摘要中的训练区间、预测区间，也不影响历史任务列表语义。

### BigScreen

- 大屏粮温趋势主图继续复用页面现有 `screenFilters.timeRange` 共享时间范围。
- 不新增图表级独立筛选状态，只补长 x 轴的 `axisLabel + rotate + dataZoom` 收口。
- 保留“粮温趋势 + 最高温”两条线，适配更长共享时间窗口。
