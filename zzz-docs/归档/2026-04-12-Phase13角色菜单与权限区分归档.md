# 2026-04-12 Phase 13 角色菜单与权限区分归档

## 范围

本次归档收口 Phase 13，目标是把后台前端菜单、默认落点、共享业务页写入口以及后端接口权限统一收口到 `ADMIN / WAREHOUSE_MANAGER / VIEWER` 三类角色语义。覆盖范围：

- `frontend/src/stores/auth.js`
- `frontend/src/router/index.js`
- `frontend/src/layout/ConsoleLayout.vue`
- `frontend/src/views/LoginView.vue`
- `frontend/src/views/DataView.vue`
- `frontend/src/views/PredictionView.vue`
- `backend/src/main/java/com/grain/platform/security/AccessControlService.java`
- `backend/src/main/java/com/grain/platform/controller/*` 中的用户、仓库、粮温、环境、预测、仪表盘后台接口

## 交付结果

### 前端

- 登录默认落点已按角色区分：
  - `ADMIN -> /dashboard`
  - `WAREHOUSE_MANAGER -> /environment`
  - `VIEWER -> /dashboard`
- 后台菜单与路由守卫统一使用 `allowedRoles`，不再存在“菜单隐藏了但路由还能进”或“路由拦了但菜单还在”的漂移。
- `DataView.vue` 与 `PredictionView.vue` 已按角色切换体验：
  - `ADMIN` 保留全功能
  - `WAREHOUSE_MANAGER` 保留所属仓库读写能力，并在前端锁仓
  - `VIEWER` 保留浏览能力，但隐藏新增、编辑、删除、导入、执行预测等写入口

### 后端

- 用户管理、仓库维护接口已收口为管理员专属。
- 粮温、环境、预测、仪表盘后台接口全部接入当前用户上下文，并统一使用角色/仓库范围门禁。
- 越权访问已使用 `ForbiddenException` 明确返回 `403`，不再混成 `400`。
- `createdBy / requestedBy` 不再写死 `1L`，已改为真实当前用户 id。
