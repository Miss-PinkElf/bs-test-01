# 开题报告

## 一、本课题要研究或解决的问题

本课题的核心目标是设计并实现一个基于Spring Boot框架的粮仓环境数据预测管理平台，主要解决以下几个具体问题。

- 1.粮仓环境数据的统一接入与规范化存储问题。当前粮仓监测系统普遍存在数据格式不统一、历史数据难以追溯的问题。本平台需要设计合理的数据库表结构，支持温度、湿度等多类环境指标的分类存储，并提供基于时间范围的高效查询接口，为后续分析与预测提供数据基础。
- 2.粮仓环境数据的趋势预测问题。仅靠实时监测数据难以提前发现潜在的粮情风险。本平台拟针对温度这一最关键的粮仓指标，结合历史时序数据，在后端集成轻量级预测模型（如基于滑动平均或简单回归的方法），对未来短期内的温度走势进行预估，并将预测结果以图表形式反馈给管理人员，辅助其作出储粮管理决策。
- 3.平台功能模块的完整性与可用性问题。平台需要具备用户管理、仓库信息管理、环境数据录入与查询、数据可视化展示、预测结果展示等基础功能模块，各模块之间逻辑清晰，接口规范，确保系统在功能上满足粮仓日常管理需求。


## 二、拟采用的研究手段（途径）

### （一）文献分析

在需求分析与技术选型阶段，系统梳理国内外关于粮仓环境监测、数据预测、物联网平台架构等方面的学术文献，重点参考赵海啸（2022）、陶善承（2023）、叶介书（2023）等近年来的研究成果，明确本平台在数据预测与可视化方面的功能定位。同时，通过文献调研厘清Spring Boot框架的典型应用模式、MySQL关系型数据库的设计规范，以及ECharts等前端可视化组件的集成方式，为系统详细设计提供理论依据。

### （二）案例分析

在系统设计阶段，对现有粮仓管理系统的典型案例进行功能分析与对比。参照郑珂瑜和孙海辰（2021）提出的物联网粮仓管理系统、韦冬雪（2023）设计的智慧粮仓系统，分析其功能模块划分方式、前后端交互逻辑及数据展示方案，归纳已有系统的优缺点，针对性地优化本平台的功能结构。在预测模块设计上，参考陶善承（2023）和赵海啸（2022）的研究方案，结合本平台实际数据规模选取计算复杂度适中的预测算法，避免过度依赖训练数据的复杂深度学习模型。

### （三）系统设计与实现路线

在技术实现层面，本平台采用前后端分离的架构模式。后端基于Spring Boot框架，提供RESTful风格的数据接口，使用MyBatis完成数据持久化操作，数据库选用MySQL；前端采用Vue.js结合ECharts实现数据的动态可视化展示，包括折线图、柱状图等常用图表形式。系统的核心开发流程为：需求分析→数据库设计→后端接口开发→前端页面开发→功能联调与测试。

预测功能的实现思路为：将历史温度数据按时间序列从数据库中提取，在后端通过Java实现简单的线性回归或加权移动平均算法，输出未来若干时间步的温度预测值，并通过接口返回前端进行图表渲染。此方案无需依赖外部机器学习框架，实现成本低，结果可解释性强，适合本课题的技术条件与研究范围。

整体而言，本课题的研究工作立足于现有文献与案例的充分调研，以功能完整、逻辑清晰的平台实现为最终目标，重点在于系统的架构设计合理性与数据预测功能的有效集成，不追求预测算法的最优性能，而着重于平台整体的可用性与工程完整性。
