# 写论文用文档索引

## 用途

本目录用于集中放置**写论文时最需要反复参考**的文档副本，减少在 `zzz-docs` 全目录里来回找材料的成本。

## 建议优先使用顺序

### 1. 课题来源与边界

- `任务书.md`
- `开题报告.md`
- `需求清单-任务书与开题报告对齐.md`

### 2. 系统需求与产品定位

- `粮仓环境数据预测管理平台-PRD-滚动预测闭环版.md`

### 3. 数据库与系统设计

- `数据库设计-滚动预测与高温预警版.md`
- `后端接口与DTO-VO-Mapper设计-滚动预测版.md`

### 4. 实现与验证材料

- `数据库优先MVP-回归验证清单.md`

## 写论文时的建议映射

- **绪论 / 研究背景**：`任务书.md`、`开题报告.md`
- **需求分析**：`需求清单-任务书与开题报告对齐.md`、`PRD`
- **系统设计 / 数据库设计**：`数据库设计-滚动预测与高温预警版.md`
- **接口与模块设计**：`后端接口与DTO-VO-Mapper设计-滚动预测版.md`
- **系统实现与测试**：`数据库优先MVP-回归验证清单.md`

## 说明

- 本目录中的文件是**复制件**，用于论文写作检索方便。
- 若你后续继续修改源文档，建议同步更新本目录中的对应副本。
