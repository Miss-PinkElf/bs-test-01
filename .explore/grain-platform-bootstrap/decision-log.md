## 完整记录

### [#1] 2026-04-05
- 决策：采用前后端分离的 Web 平台作为毕业设计落地方向。
- 原因：与开题报告中的 Spring Boot + Vue + ECharts + MySQL 路线一致，最适合做可演示平台。

### [#2] 2026-04-05
- 决策：将实现范围收敛为软件平台 MVP，不实现真实硬件接入、机器人与数字孪生。
- 原因：这些内容属于文献背景，不是当前开题报告要求的最小交付物。

### [#3] 2026-04-05
- 决策：角色先采用管理员、仓库管理员、查看者三类。
- 原因：权限模型足够覆盖毕业设计常见演示场景，同时避免权限系统过度复杂。

### [#4] 2026-04-05
- 决策：预测算法先采用可解释的简单线性回归与移动平均思路。
- 原因：符合开题报告，不依赖额外机器学习框架，便于本科答辩解释。

### [#5] 2026-04-05
- 决策：一键脚本优先做“环境检查 + 启动”，而不是自动安装所有依赖。
- 原因：当前环境缺少 Maven，且网络受限，直接安装依赖的成功率不可控。
