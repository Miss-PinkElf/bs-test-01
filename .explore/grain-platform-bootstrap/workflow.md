# 任务工作流

## 任务目标
- 基于开题报告，沉淀一个可实施的粮仓环境数据预测管理平台方案。
- 产出数据库设计、页面清单、接口清单。
- 初始化可继续开发的前后端项目骨架与一键启动脚本。

## 范围边界
- 范围内：
  - 后端 Spring Boot 项目骨架
  - 前端 Vue + ECharts 项目骨架
  - 数据库表设计
  - 角色权限建议
  - 一键启动脚本
  - 与开题报告一致的 MVP 功能范围
- 范围外：
  - 真实物联网设备接入
  - 机器人、数字孪生、区块链实现
  - 复杂机器学习训练流程
  - 生产级部署

## 成功标准
- `.explore/` 中存在完整 mission 记录与 spec 文档。
- 仓库内存在 `backend/`、`frontend/`、`scripts/`、`README.md` 等基础结构。
- 设计说明能直接支持后续毕业设计编码与答辩演示。
- 启动脚本能完成环境检查，并在依赖齐备时启动前后端。

## 阶段规划
1. Mission Init
2. Align 与 Propose
3. Apply：创建骨架、脚本、说明文档
4. Checkpoint 与交付说明

## 当前阶段
- Handoff / Ready for resume

## 退出条件
- 用户可直接查看 spec、项目骨架、脚本和说明。
