# 任务工作流

## 任务目标
- 基于开题报告与老师最新要求，沉淀一个可实施的粮仓环境数据预测管理平台方案。
- 以数据库设计和预测闭环留痕为核心，完成粮温导入、汇总分析、滚动预测、验证修正和高温预警的实现路线。
- 在现有项目基础上完成必要的半重写，而不是继续沿旧短期预测路线补丁式推进。

## 范围边界
- 范围内：
  - 后端 Spring Boot + MyBatis
  - 前端 Vue + ECharts
  - 数据库重构
  - 粮温 XLS 导入
  - 粮温原始测点与汇总分析
  - 滚动预测任务与修正预测版本链
  - 高温预警
  - 启动脚本与恢复文档
- 范围外：
  - 真实物联网设备接入
  - 机器人、数字孪生、区块链实现
  - 复杂机器学习训练流程
  - 生产级部署

## 成功标准
- `.explore/` 中存在完整 mission 记录、最新 handoff 和可恢复提示词。
- 仓库内存在与滚动预测闭环一致的 PRD、数据库设计、接口设计和 mock 数据方案。
- `backend/src/main/resources/db/schema.sql` 与新真相源对齐。
- 后续开发可以直接从“导库验证 -> 后端改造 -> 前端改造”继续。

## 阶段规划
1. Mission Init
2. Align 与 Propose
3. 旧路线 Apply：项目骨架、真实持久层、前端骨架
4. Realign：老师新要求对齐与真相源重写
5. Apply：数据库重构、后端改造、前端改造
6. Checkpoint 与交付说明
