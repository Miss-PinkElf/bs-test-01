# 决策日志

## 2026-03-24 决策：优先修复渲染生命周期，而不是继续调视觉参数
- **背景**：拖拽/缩放后出现 `screen/removeChild`、模型消失、模型过大等问题。
- **选择**：先保证 `PIXI.Application` 不因窗口尺寸变化而重复销毁，再修正模型适配比例算法。
- **原因**：如果生命周期没稳定，继续调边框、toolbar 或视觉参数只会放大问题。
- **放弃的方案**：继续增加缩放系数常量微调；这只能掩盖模型过大的症状，不能解决根因。
- **影响**：本轮实现会优先修改 `Live2DCanvas.tsx`、`useLive2DModel.ts`、`App.tsx`，并同步记录问题原因。
