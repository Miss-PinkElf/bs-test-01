# 普通环境数据保存无反馈修复

## 背景（Mini Align）

- **目标**：修复数据管理页中普通环境数据（湿度 / 二氧化碳）弹窗点击“保存修改 / 提交数据”后无明显反馈的问题。
- **范围**：仅调整 `frontend/src/views/DataView.vue` 的提交交互、前端最小校验与提示，不改后端接口契约，不扩散到粮温主线。
- **已确认口径**：
  - 当前用户实际感知是“点击保存没有反应”。
  - 环境数据前后端 CRUD 代码已存在，本轮优先修“提交失败不可感知”。
  - 若修完前端反馈后暴露后端错误，再以错误信息为依据做下一轮收口。

## 问题记录（现象 / 原因 / 解决）

| 项 | 内容 |
| --- | --- |
| **现象** | 在普通环境数据弹窗内点击“保存修改”或“提交数据”后，页面没有成功提示，也没有失败提示，用户只能感知为“没反应”。 |
| **原因** | `DataView.vue` 中的 `submit()` 为异步函数，但没有 `try/catch` 和提交态控制；一旦请求失败或参数不合法，异常会中断流程且不会通过页面提示反馈给用户。 |
| **解决** | 为提交链路补 `try/catch/finally`、提交中 loading、最小前端校验；仅在请求成功后关闭弹窗并刷新列表，失败时明确弹出错误提示。 |
