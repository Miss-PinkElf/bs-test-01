# Quick Task Summary: 260410-k32

**Completed:** 2026-04-10  

**Description:** Vue 管理端：温度预测页（及同类主内容区）进入后页面横向持续变宽、右侧元素被不断外推；修复为「主内容原生滚动 + flex 收紧 + ECharts 显式 resize」。

## 根因（摘要）

- Element Plus `el-scrollbar` 在 `onUpdated` 中调用 `update()`，并对包裹层使用 `useResizeObserver`。
- ECharts 5 对图表容器亦有尺寸监听与 `resize`。
- 二者与 flex 子项默认 `min-width: auto` 叠加时，易出现横向尺寸反馈，表现为宽度「越撑越大」。仅加 `min-width: 0` 不足以稳定消除反馈。

## Deliverables

- 主内容区移除 `el-scrollbar`，改为 `.console-main-native` 原生纵向滚动并禁止横向溢出。
- `flex: 1 1 0`、顶栏与栅格等处的 `min-width: 0` 约束保留并补强。
- `PredictionView` 内在 `rAF` 后显式 `chart.resize`（零动画）。
