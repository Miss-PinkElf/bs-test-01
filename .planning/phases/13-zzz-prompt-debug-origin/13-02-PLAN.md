## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| auth store → router / ConsoleLayout / page-level actions | 前端菜单、路由和按钮权限必须共享同一套角色能力判断，否则会出现“菜单隐藏了但路由能进”或“路由拦了但按钮还在”的漂移。 |
| `WAREHOUSE_MANAGER` 前端仓库选择 → 后端仓库范围 | 仓库管理员前端需要主动锁仓，不能完全依赖后端拒绝，否则体验与角色语义不一致。 |

| T-13-05 | T | 仓库管理员仓库切换 | mitigate | `DataView` 与 `PredictionView` 对 `WAREHOUSE_MANAGER` 固定 `managedWarehouseId`，减少前端越仓操作面。 |
