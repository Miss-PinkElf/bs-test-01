|------|------|
| 公共大屏浏览器 → `/api/dashboard/screen` | `/screen` 为公开路由，大屏接口必须只返回演示级聚合数据与既有明细，不扩出账号或管理字段。 |
| Dashboard 聚合层 → 底层 Mapper SQL | 新趋势查询参数来自浏览器，必须继续使用参数化 SQL 与时间/仓库条件过滤，不把前端值拼接进 SQL 字符串。 |

## STRIDE 登记

| Threat ID | 类别 | 组件 | 处置 | 缓解 |
|-----------|------|------|------|------|
| T-08-01 | I | `/api/dashboard/screen` | 缓解 | 仅返回已有概览、趋势和任务摘要字段，不回传用户信息、手机号、备注等无关敏感数据。 |
| T-08-02 | D | 大屏聚合查询 | 缓解 | 聚合查询按 `warehouseId`、`startTime`、`endTime` 过滤，结果条数限制在演示级窗口，避免全量扫表导致公开页卡顿。 |
