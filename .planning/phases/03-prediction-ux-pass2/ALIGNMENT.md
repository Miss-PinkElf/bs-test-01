# Phase 3 需求对齐：温度预测页交互二次优化

**日期：** 2026-04-10  
**触发：** 执行预测后需滚到页底才能看到曲线；双表用途对初次使用者不直观。

## 问题

1. **图表可达性：** Phase 2 将图表置于「预测结果 + 历史归档」之下，执行预测后主视觉在视口外，流程不顺。
2. **双表语义：** 「预测结果列表」= 当前任务逐步明细（ACTUAL/FUTURE）；「历史归档」= 历次任务，点击切换当前任务。缺少一句话说明时易被当成重复表格。

## 本期目标

| 项 | 做法 |
| --- | --- |
| 区块顺序 | 参数 + 摘要 → **双线图** → 两表（先见曲线，再查表） |
| 文案 | 两表卡片标题下增加 **一行副标题**（用途 + 历史表「点击行切换」） |
| 可选增强 | 预测成功后 **平滑滚动** 至图表卡片，减少「点了没反应」感 |

## 不做

- 不改后端、不合并数据库语义；仍为两张表，仅澄清交互与布局。

## 验收

- 点击「执行预测」后，无需滚到页底即可看到图表（常规视口高度下）。
- 新用户读副标题能区分「当前任务明细」与「历史任务列表」。
- 常见桌面宽度下「滚动预测参数」与「任务摘要」**左右并排**（非误堆成上下两块）。
