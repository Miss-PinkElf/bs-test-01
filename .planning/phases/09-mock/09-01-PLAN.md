<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 浏览器 -> 用户/仓库/预测分页接口 | keyword、pageNum、pageSize 为不可信输入，必须在 controller/service 层做参数归一化并通过 MyBatis 参数绑定传入 SQL。 |
| PredictionService -> PredictionTaskMapper / PredictionResultMapper | 预测分页仍会组装完整结果列表，必须限制为当前页 task 集合，避免回退到全量读取。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | T | `UserMapper.xml` / `WarehouseMapper.xml` / `PredictionTaskMapper.xml` | mitigate | 所有 keyword 条件继续用 MyBatis `#{keyword}` 参数绑定，不拼接原始 SQL 字符串。 |
| T-09-02 | D | `PredictionService.listTaskPage` | mitigate | 先分页 task 主表，再只对当前页 task 调用 `toResponse(...)`，避免全量任务 N+1 组装。 |
| T-09-03 | I | `/api/users/stats` / `/api/warehouses/stats` | accept | 仅返回页面已有 summary card 所需计数字段，不新增敏感明细。 |
</threat_model>
