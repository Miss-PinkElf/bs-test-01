# 对话后端专项工作流

## 任务目标
围绕 Phase B 的“简单对话 + 后端最小闭环”推进后端服务、前端请求层、事件协议和联调验证，并将成果平滑转入记忆 MVP 阶段。

## 范围边界
- 范围内：本地 HTTP 通信、后端服务骨架、前端对话入口、消息状态、事件协议、联调证据、记忆 MVP 准备。
- 范围外：长期人格、复杂 agent 编排、语音、多模态、重型记忆系统设计。

## 成功标准
- 前端可以发送文本到 Python 后端并收到真实模型回复。
- 后端可以通过事件流主动驱动前端气泡、情绪和状态面板更新。
- 当模型服务不可用时，前端能收到明确错误。
- 有一轮可复用的联调与验证记录。
- 进入下一阶段时，记忆接口保持稳定，不因底层适配器更换而破坏聊天主链路。

## 当前状态
- “简单对话 + 后端最小闭环” 已完成。
- 高层事件协议与最小 `Pet Controller` 已达到基础可用状态。
- 当前专项应从“跑通链路”切换为“把记忆服务做成 MVP”。
