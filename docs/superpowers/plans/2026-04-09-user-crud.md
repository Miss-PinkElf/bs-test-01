# User CRUD Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为后台管理补齐用户新增、编辑、删除、重置密码与多角色维护，形成完整用户管理 CRUD 闭环。

**Architecture:** 后端沿用现有 Spring Boot + MyBatis `Controller / Service / Mapper.xml` 结构，在 `sys_user` 与 `sys_user_role` 上补齐写接口与业务保护；前端沿用 Element Plus 管理页模式，在 `UsersView.vue` 中增加弹窗与操作列，并复用已有角色、仓库选项接口。

**Tech Stack:** Spring Boot、MyBatis XML、Vue 3、Element Plus、Axios
